# AlertaMuni

**Reporte inteligente de problemas urbanos**

AlertaMuni es una plataforma para registrar, geolocalizar y dar seguimiento a incidencias urbanas, conectando a ciudadanos con las entidades responsables de su atención.

## Stack definido
- Mobile: Kotlin / Android
- Web: React
- Backend: Java + Spring Boot
- Base de datos: PostgreSQL
- Arquitectura backend: Monolito modular preparado para evolucionar a microservicios
- Gestión: Trello
- Control de versiones: Git + GitHub

## Flujo de ramas
- main: versión estable
- develop: integración
- feature/*: funcionalidades
- fix/*: correcciones
- docs/*: documentación
