# Línea base SRS v1.0 — AlertaMuni

La versión 1.0 del SRS queda establecida como línea base para iniciar el desarrollo del MVP después del levantamiento ciudadano.

## Prioridades consolidadas
**Must:** autenticación, registro de incidencia, fotografía, ubicación, categoría, descripción, consulta de reportes propios, seguimiento, web de gestión básica, estados, asignación e historial.

**Should:** mapa básico, detección de posibles duplicados, apoyo ciudadano, notificaciones y filtros.

**Future:** validación institucional completa, IA avanzada, SaaS multi-entidad y migración efectiva a microservicios.

Los cambios posteriores derivados de retroalimentación del profesor deberán gestionarse como cambios de alcance y mantener trazabilidad con Trello, GitHub y la documentación oficial.
